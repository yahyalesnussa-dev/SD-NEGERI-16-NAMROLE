Petunjuk Penggunaan Aplikasi

Panduan lengkap penggunaan E-Absensi SD Negeri 16 Namrole berdasarkan peran masing-masing pengguna.

Panduan untuk Guru & Admin

Absensi Harian, Lokasi GPS & Tanda Tangan

  1. Registrasi / Login: Daftar akun baru menggunakan NIP/Username, pilih peran Guru atau Admin, dan catat Kode Pemulihan untuk berjaga-jaga jika lupa sandi.
  2. Aktifkan Lokasi (GPS): Izinkan browser mengakses lokasi perangkat agar sistem mendeteksi koordinat dan jarak Anda dari SD Negeri 16 Namrole.
  3. Tanda Tangan Digital: Pada menu Absensi Harian, pilih status kehadiran lalu bubuhkan tanda tangan langsung di kotak kanvas menggunakan jari atau mouse.
  4. Absen Masuk & Pulang: Klik tombol hijau Simpan Absen Masuk di pagi hari, dan tombol kuning Simpan Absen Pulang saat selesai jam mengajar.
  5. Tugas Khusus Admin: Admin dapat melihat seluruh rekap absensi semua guru, menghapus data ganda/keliru, mengelola akun guru, serta mencetak laporan bulanan.

Panduan untuk Kepsek & Pengawas

Monitoring, Verifikasi & Cetak Laporan

  1. Akses Monitoring Penuh: Login dengan akun berperan Kepsek/Pengawas untuk memantau kehadiran seluruh guru SD Negeri 16 Namrole secara real-time.
  2. Verifikasi Lokasi & TTD: Buka menu Rekap & Cetak Laporan. Anda dapat memeriksa jam masuk, jam pulang, titik koordinat GPS (klik untuk buka peta), serta keaslian tanda tangan digital setiap guru.
  3. Filter Bulanan & Pencarian: Gunakan kolom Filter Bulan untuk menyaring laporan per bulan (misal untuk laporan tunjangan/kinerja) atau cari nama guru tertentu.
  4. Cetak / Print PDF Resmi: Klik tombol Cetak / Print PDF. Dokumen akan otomatis diformat dengan Kop Surat SD Negeri 16 Namrole dan kolom pengesahan Kepala Sekolah & Pengawas.
  5. Unduh Excel (CSV): Klik Unduh CSV/Excel jika ingin mengolah data kehadiran lebih lanjut di Microsoft Excel.

Lupa Kata Sandi atau Ingin Install di HP?

Gunakan tab Lupa Sandi pada halaman login dengan memasukkan NIP & Kode Pemulihan, atau hubungi Admin Sekolah. Klik tombol di samping untuk panduan instalasi di layar utama HP.
